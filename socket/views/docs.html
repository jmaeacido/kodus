1. Quick Start

Step 1: Register a User

Register and get a token from the server using the interactive test page.

Registration: Go to /test and use the registration form to get your authentication token.
Important: Save the token from the response! You'll need it for all future requests.

Step 2: Connect to Socket.IO

const socket = io('APP_URL', {
  auth: { token: 'YOUR_TOKEN_HERE' }
});

Step 3: Subscribe to a Channel

socket.emit('subscribe', 'my-channel');

Step 4: Send and Receive Messages

// Send a broadcast
socket.emit('broadcast-event', {
  channel: 'my-channel',
  event: 'message',
  data: { text: 'Hello!' }
});

// Listen for messages
socket.on('message', (data) => {
  console.log('Received:', data);
});

2. User Registration

Register a new user to get an authentication token. Registration is done through the interactive test page UI.

Register via Test Page: Visit /test and fill in the registration form with your name and purpose.

Registration Form

On the test page, you'll find a registration form where you can:

  1. Enter your name
  2. Enter your purpose
  3. Click "Register & Get Token"
  4. Copy and save your token from the displayed result

Response

After successful registration, you'll receive:

{
  "success": true,
  "message": "User registered successfully",
  "user": {
    "id": 1,
    "name": "Your Name",
    "purpose": "Your Purpose",
    "token": "64-character-hexadecimal-token"
  }
}
Token Information:
  • Tokens are 64-character hexadecimal strings
  • Each registration creates a unique token
  • Tokens are stored in SQLite database
  • Save your token immediately - you'll need it for authentication
API Endpoint Available: While registration is recommended via the UI, the API endpoint POST /register is also available for programmatic registration if needed.

3. Socket.IO Connection

Authentication Required: All Socket.IO connections require a valid token. Without a token, the connection will be rejected.

Method 1: Using auth Object (Recommended)

const socket = io('APP_URL', {
  auth: {
    token: 'YOUR_TOKEN_HERE'
  }
});

Method 2: Using Query Parameter

const socket = io('APP_URL?token=YOUR_TOKEN_HERE');

Connection Events

// Connection successful
socket.on('connect', () => {
  console.log('Connected! Socket ID:', socket.id);
});

// Connection error (invalid token, etc.)
socket.on('connect_error', (error) => {
  console.error('Connection error:', error.message);
});

// Disconnected
socket.on('disconnect', (reason) => {
  console.log('Disconnected:', reason);
});

4. Broadcasting Messages

Method 1: Via API Endpoint

POST /broadcast (Requires Authentication)

Token Methods: You can provide the token in three ways:

  • Authorization header: Authorization: Bearer <token>
  • Request body: {"token": "<token>", ...}
  • Query parameter: ?token=<token>

Example Request

curl -X POST APP_URL/broadcast \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "channel": "test-channel",
    "event": "message",
    "data": {
      "text": "Hello World",
      "timestamp": "2024-01-01T12:00:00Z"
    }
  }'

Method 2: Via Socket.IO

Send broadcasts directly from a Socket.IO client:

socket.emit('broadcast-event', {
  channel: 'test-channel',
  event: 'message',
  data: {
    text: 'Hello from Socket.IO!',
    timestamp: new Date().toISOString()
  }
});

Receiving Broadcasts

Listen for broadcasts in your Socket.IO client:

// Listen for specific event
socket.on('message', (data) => {
  console.log('Message received:', data);
  // data will include: { text, timestamp, fromUser, ... }
});

// Listen for any event (recommended for testing)
socket.onAny((eventName, ...args) => {
  console.log('Event received:', eventName, args);
});
Tip: Use socket.onAny() to catch all events, including custom event names like "event-name" from your broadcasts.

5. Channel Management

Subscribe to Channel

Join a channel to receive broadcasts sent to that channel.

socket.emit('subscribe', 'channel-name');
Note: You must be subscribed to a channel to receive broadcasts sent to that channel.

Leave Channel

Leave a channel to stop receiving broadcasts.

socket.emit('leave', 'channel-name');

Multiple Channels

You can subscribe to multiple channels:

socket.emit('subscribe', 'channel-1');
socket.emit('subscribe', 'channel-2');
socket.emit('subscribe', 'channel-3');

6. Complete Examples

Example 1: Basic Chat Application

// 1. Connect with token
const socket = io('APP_URL', {
  auth: { token: 'YOUR_TOKEN' }
});

// 2. Wait for connection
socket.on('connect', () => {
  console.log('Connected!');
  
  // 3. Subscribe to chat channel
  socket.emit('subscribe', 'chat-room');
});

// 4. Send message
function sendMessage(text) {
  socket.emit('broadcast-event', {
    channel: 'chat-room',
    event: 'chat-message',
    data: { text, user: 'MyName' }
  });
}

// 5. Receive messages
socket.on('chat-message', (data) => {
  console.log(`${data.fromUser}: ${data.text}`);
});

Example 2: Real-time Notifications

const socket = io('APP_URL', {
  auth: { token: 'YOUR_TOKEN' }
});

socket.on('connect', () => {
  // Subscribe to user-specific notification channel
  socket.emit('subscribe', `notifications-user-123`);
});

// Listen for notifications
socket.on('notification', (data) => {
  showNotification(data.message);
});

Example 3: Using API to Send Broadcasts

// Send broadcast via API (e.g., from backend server)
async function sendBroadcast(channel, event, data) {
  const response = await fetch('APP_URL/broadcast', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${YOUR_TOKEN}`
    },
    body: JSON.stringify({
      channel,
      event,
      data
    })
  });
  
  return await response.json();
}

// Usage
sendBroadcast('notifications', 'alert', {
  message: 'New update available!',
  type: 'info'
});

7. Troubleshooting

Connection Fails with "Token required"

Problem: Socket.IO connection is rejected.

Solution:

  • Make sure you're providing the token
  • Check that the token is correct (64 characters)
  • Verify the token exists in the database (register again if needed)

Not Receiving Broadcasts

Problem: Broadcasts are sent but not received.

Solution:

  1. Verify you're subscribed to the correct channel: 
    socket.emit('subscribe', 'channel-name');
  2. Check that the channel name matches exactly (case-sensitive)
  3. Verify your Socket.IO connection is active: 
    console.log('Connected:', socket.connected);
  4. Use socket.onAny() to catch all events, not just "message"
  5. Make sure you're connected and subscribed before sending the broadcast
Common Issue: If you send a broadcast via curl before subscribing to the channel, you won't receive it. Always subscribe first!

"Invalid or expired token" Error

Problem: API requests return 403 error.

Solution:

  • Token might be incorrect
  • Register a new user to get a fresh token
  • Check that you're sending the token correctly (header, body, or query)

Broadcast API Returns 401

Problem: Broadcast endpoint returns "Token required".

Solution:

  • Include token in Authorization header: Authorization: Bearer <token>
  • Or include in request body: {"token": "<token>", ...}
  • Or include in query: ?token=<token>
